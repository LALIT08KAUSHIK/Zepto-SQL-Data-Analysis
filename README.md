# Zepto-SQL-Data-Analysis
Analyzed Zepto’s e-commerce inventory dataset end to end using SQL, performing data cleaning, exploration, and business analysis to uncover insights into product pricing, stock availability, category performance, and revenue opportunities.

## Project Overview
This project focuses on analyzing Zepto's e-commerce inventory dataset using PostgreSQL to extract meaningful business insights. It involves working with raw retail data, performing data exploration and cleaning, and solving real-world business problems through SQL queries.

## Key Activities
- **Database Setup:** Created database tables and imported the raw Zepto inventory dataset into PostgreSQL.
- **Data Exploration:** Examined product categories, pricing, stock availability, missing values, and duplicate records.
- **Data Cleaning:** Handled missing and duplicate records, identified invalid pricing values, and converted prices from paise to rupees.
- **Business Analysis:** Developed SQL queries to analyze product performance, inventory distribution, pricing trends, revenue opportunities, and product segmentation.

## Key SQL Concepts Used
- Aggregate Functions
- GROUP BY and HAVING
- CASE WHEN Statements
- Common Table Expressions (CTEs)
- Subqueries
- Data Cleaning and Transformation
- Business-oriented SQL Analysis

## Tools & Technologies
- PostgreSQL
- SQL
- Zepto Inventory Dataset

## Objective
To strengthen practical SQL skills by transforming raw e-commerce inventory data into actionable business insights and demonstrating real-world data analysis techniques.
